# Augment RM Anomaly Detector Platform

A platform for detecting anomalies in risk management data using machine learning and statistical techniques.

## Upstream Projects

This platform builds upon and integrates with the following upstream open-source projects:

- **[Azure Sentinel](https://github.com/Azure/Azure-Sentinel)** — Cloud-native SIEM and security analytics from Microsoft Azure.
- **[Hummingbird](https://github.com/microsoft/hummingbird)** — A library for compiling traditional ML models into tensor computations for fast inference.
- **[Sphinx](https://github.com/sphinx-doc/sphinx)** — The documentation generator used throughout this project.

## Overview

The Augment RM Anomaly Detector Platform provides end-to-end capabilities for ingesting, processing, and analyzing risk management data to detect anomalies. It leverages modern ML pipelines and integrates with Azure Sentinel for security monitoring and alerting.
